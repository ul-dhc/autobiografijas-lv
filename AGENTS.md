# Bilingual website

Apply every user-requested content, layout, navigation, link and interaction change to both Latvian and English versions in the same change. Translate new editorial text and labels into English. Keep archival quotations, source document titles and personal names faithful to the source; do not invent expanded identities or abbreviations. Check both languages on desktop and mobile when changing the interface. Run the language-parity verification with the normal build checks before publishing. Do not treat one language as finished while its counterpart remains outdated.
